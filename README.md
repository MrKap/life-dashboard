# My Life Dashboard

An installable, ADHD-friendly personal dashboard for schedule, university, basketball, gym, rehab and sleep.

## Current modules

- Today view with next-up and leave-home emphasis
- Editable weekly schedule
- University task tracking
- Sunday basketball game-time planning
- Rehab checklist
- Gym A / Gym B workout builder
- Gradual sleep-shift tracker
- Local backup / restore
- Offline-capable PWA structure

## Future gym development

The app is deliberately structured so the gym section can grow into a proper exercise library. Planned fields include:

- equipment / machine available
- muscle group and movement pattern
- neutral-grip friendly
- cuff / strap friendly
- wrist sensitivity
- knee / tendon loading category
- sets, reps and load
- reps in reserve / RPE
- workout history and progression
- saved Gym A / Gym B templates

## Data

For now, personal edits are saved locally in the browser on the device using the app. The Backup button exports a JSON copy that can be restored later.

## Hosting

This repository is designed to be hosted as a Progressive Web App using GitHub Pages. Once Pages is enabled, open the HTTPS site in Chrome on Android and choose **Install app** or **Add to Home screen**.
